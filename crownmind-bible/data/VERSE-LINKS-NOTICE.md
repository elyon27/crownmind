# Verse links and study content

Verse links combines outgoing references from OpenBible.info with explicitly labeled CrownMind topic and Old/New Testament connections. It is an indexed study aid, not a claim to enumerate every possible theological interpretation.

OpenBible.info cross-reference data: https://www.openbible.info/labs/cross-references/
License: Creative Commons Attribution 4.0 International, https://creativecommons.org/licenses/by/4.0/
The upstream source draws primarily on the Treasury of Scripture Knowledge. Book codes are converted to CrownMind slugs; cross-chapter ranges are split; duplicate target ranges are merged; references not represented in the bundled KJV edition are omitted. No Scripture wording is imported from the cross-reference source. Original Bible translation licenses remain in the existing notices. A source hash, source-row count, omitted-row count and attribution are written to the generated cross-reference metadata on every build.

Reference numbering uses conventional KJV coordinates, not an automatic verse-number concordance for Douay–Rheims or other editions. This is stated in the Verse links panel. Readers can select a translation for passage previews; unavailable numbered text is reported instead of silently substituted.

CrownMind's expanded topics contain seven curated passages each. Spiritual/thematic relations are marked as such. Old/New Testament links distinguish typology, New Testament applications and thematic connections rather than representing all 72 as direct predictive prophecies.
